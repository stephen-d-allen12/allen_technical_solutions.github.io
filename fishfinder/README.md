# Allen Fish Finder

This folder is the published Allen Fish Finder website: the sales pages, with the app under `app/`.
It is built from the `allen_fish_finder` repository, so don't edit these files here. Change the
source there, then run its `scripts/publish.sh` to replace this folder. The one exception is
`app/reports/`, which the *Fish finder reports* workflow refreshes four times a day.
